# Gaming Shop Frontend

This directory contains the React and Vite frontend for Gaming Shop.

## Features

- Game catalog pagination
- Live game-title search
- Game detail pages
- Shopping cart
- Persistent cart data using browser local storage
- Responsive dark-themed interface

## Run

```powershell
npm install
npm run dev
```

The frontend expects the Express API at `http://localhost:3000`.

## Scripts

```powershell
npm run dev      # Start the development server
npm run build    # Create a production build
npm run lint     # Run Oxlint
npm run preview  # Preview the production build
```

See the repository-level [README](../README.md) for PostgreSQL setup and complete application instructions.
